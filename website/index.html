What is Memero?

Memero is a private cryptocurrency forked from Lolnero (itself a fork of Wownero and Monero). It keeps SHA-3-256 mining and anonymous transactions, but replaces the original flat reward with a Monero-style exponential decay toward a fixed 18.4 million MEM hard cap — no tail emission, no premine, no dev tax.

Get started

Build from source:

mkdir build && cd build
CC=gcc-13 CXX=g++-13 cmake ..
make -j$(nproc)

Run a node:

./build/bin/memerod-rpc --data-dir ~/.memero
